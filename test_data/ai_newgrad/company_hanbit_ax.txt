[가상 회사 - 테스트용] 한빛AX 2026 하반기 신입 공채 - AI 엔지니어

■ 회사 소개
한빛AX는 제조·금융·공공 고객사의 AI 전환(AX)을 돕는 IT 서비스 기업입니다. 직원 3,200명, 고객사 140곳.
2025년부터 사내 생성형 AI 플랫폼 "한빛 Copilot"을 고객사 내부망에 설치형으로 공급하고 있습니다.

■ 주요 사업
- 제조: 설비 점검 보고서 자동 작성, 품질 불량 원인 검색 챗봇
- 금융: 상품 약관·내규 검색 RAG, 상담 내용 요약
- 공공: 민원 분류 자동화, 내부 규정 질의응답

■ 직무: AI 엔지니어 (신입, 00명 채용)
- 고객사 문서 기반 RAG 시스템 구축과 성능 개선
- LLM 응답 품질 평가 체계(평가 세트, 지표) 설계
- 고객사 현업 담당자와 요구사항 정리, PoC 진행
- FastAPI 기반 AI 서비스 API 개발과 배포

■ 자격 요건
- Python 개발 경험
- LLM API 또는 RAG를 활용한 프로젝트 경험
- 팀 프로젝트 경험과 협업 도구(Git) 사용 경험

■ 우대 사항
- 벡터 DB(pgvector, FAISS, Chroma 등) 사용 경험
- 응답 품질을 수치로 평가하고 개선해 본 경험
- 클라우드(AWS, Azure) 배포 경험
- 정보처리기사 등 관련 자격증

■ 인재상
1. 고객의 일을 먼저 이해하는 사람: 기술보다 고객사 현업의 문제를 먼저 묻는다
2. 근거로 말하는 사람: "좋아졌다" 대신 "얼마나, 무엇으로 쟀는지"를 말한다
3. 끝까지 책임지는 사람: PoC로 끝내지 않고 운영까지 챙긴다

■ 전형 절차
서류 → 코딩테스트 → 1차 직무면접(기술 + 과제 발표) → 2차 임원면접 → 입사
