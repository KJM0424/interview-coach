# 포트폴리오 [가상 인물 - 테스트용]

## 사내 규정 검색 챗봇 (4인, 팀장, 2025.11 ~ 2025.12)

### 문제
- 내규 PDF 86개를 그대로 500자씩 잘라 넣었더니, 조항 중간이 잘려 근거가 엉뚱하게 나옴
- 프롬프트를 5번 고쳤지만 체감상 나아지지 않았고, 나아졌는지 잴 방법이 없었음

### 내가 한 일
1. 평가 세트: 팀원과 질문 120개 작성, 질문마다 정답 근거 조항 표시
2. 지표: 정답 근거가 상위 3개 안에 들어오는 비율(Top-3 포함률)
3. 청킹 변경: 고정 길이 → 조항 단위, 조항 번호·문서명을 메타데이터로 추가
4. 결과: Top-3 포함률 0.48 → 0.74
5. 검색 결과 없는 질문은 "규정에서 찾지 못했어요"로 답하게 해서 지어낸 답변 줄임 (지어낸 답변 비율은 따로 측정 못 함)

### 기술
FastAPI, LangChain, Chroma, OpenAI 임베딩, Streamlit, AWS EC2

### 아쉬운 점
- 표가 들어간 PDF는 표 내용이 깨져서 검색이 잘 안 됨. 해결 못 하고 한계로 발표함
- 응답 시간은 평균 4초 정도였고 개선하지 못함

- 담당: 전사 후처리, 요약 프롬프트
